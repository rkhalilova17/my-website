# My Personal Website – Rubabe Khalilova

## Project Description:
This project is my personal website created for my Web and Mobile I course.  
It includes multiple HTML pages: **Homepage**, **Education**, **Schedule**, **Contact Me**, and **Questionnaire**.  
Each page is connected with navigation links, and the site also includes a responsive layout and a contact form.

## What I Learned
During this project, I learned:
- How to structure web pages using HTML5 elements like `<header>`, `<nav>`, `<section>`, and `<footer>`.
- How to link multiple pages together.
- How to create and style forms.
- How to use layout techniques like **Float**, **Flexbox**, and **Grid**.
- How to host a website on **GitHub Pages**.

## Purpose of the Website
The purpose of this website is to serve as a **personal portfolio and practice project** for learning web development fundamentals.
